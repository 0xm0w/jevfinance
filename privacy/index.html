Privacy

The short version: this site collects nothing. JevFinance is a statically-generated website. Every page — the daily edition, the research dossiers, the workbench, the portfolio ledger — is a pre-built file served from a CDN. There are no accounts, no logins, no forms, no analytics scripts, no tracking pixels, and no cookies set by us.

Infrastructure: the site is hosted on Vercel. Like all hosting providers, Vercel processes standard request logs (IP address, user agent, requested URL) as part of delivering pages; that data is governed by Vercel's privacy policy, not ours, and we do not receive or store individual visitor records. The one dynamic element on the daily edition is a price check fetched directly from a public market API by your own browser; that request goes from your browser to the API, not through us.

Data we publish: everything on this site is public by design — market data, model outputs, paper-trading decisions. The portfolio is simulated with paper money for research transparency; nothing here is investment advice, and no user trading data exists because none is collected.
