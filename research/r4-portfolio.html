The known-answer test feeds a strategy that is always fully allocated and checks the engine reproduces the raw price series to machine precision. The no-look-ahead property is structural: a decision taken at close t is only ever applied to the t→t+1 return, so yesterday's score drives today's exposure — never today's.

Who does what — jev vs GLM

jev — the decision layer (typed, gated). Each run produces a typed decision {from, to, direction: upgrade|downgrade|hold, probabilities} derived from the temperature bands and the regime gate. In this backtest the policy stands in for jev (historical jev calls are impossible); live, jev makes the same call from richer unstructured input — news tone, Reddit capitulation language, divergence causes — inside the same typed contract and the same 2-day confirmation, so a hallucinated upgrade cannot pass the schema, and the probability gate can refuse low-confidence moves.

GLM 5.3 MAX — the execution layer (words and orchestration, not math). It translates an approved level change into orders (size the delta, respect venue limits, split if shallow books), writes the fact-bound blog line about the change, handles incidents, and logs the run. It never chooses the level — the same rule that makes the index honest makes the portfolio honest: agents orchestrate, typed code computes.

Limitations

Long-only spot simulation on daily closes; intraday fills, funding, and borrowing are out of scope. The band thresholds (30/45/55/70) come from the R1 sweep's temperature bands, not from optimizing this portfolio — but they were chosen knowing the data, so treat relative (not absolute) performance as the finding. P(bull) is walk-forward refit yearly; 2021+ only. Costs are linear approximations. Past regime structure may not repeat; the level system's value is drawdown control, and that is the claim this data supports.
